# Ильсур - Питух

Закрытый каталог браузерных игр для компании друзей. Сейчас в каталоге две
игры; проект устроен так, чтобы пополнять его новыми играми. Играть можно на
компьютере и телефоне, а для каждой игры ведётся отдельный рейтинг.

## Игры

| Игра                    | Адрес                  | Управление и экран                                      |
| ----------------------- | ---------------------- | ------------------------------------------------------- |
| «Ильсур ловит члены»    | `/ilsur-lovit-chleny/` | Клавиатура на компьютере, горизонтальный экран телефона |
| «Ильсур-Пакман-Членоед» | `/packman/`            | Клавиатура на компьютере, вертикальный экран телефона   |

Каталог и вход находятся по адресу `/`. Перед запуском каждой игры доступна
инструкция. Из игры можно вернуться в каталог, сохранив сессию. Рейтинги
раздельные: на странице игры показываются её результаты и личное место игрока.

## Окружение и установка

Нужны Node.js 22.13 или новее и npm (`nvm use`, если установлен nvm).

```sh
npm ci
npx playwright install chromium webkit
```

Для локальной разработки создайте `.env` на основе `.env.example` и задайте
пароль входа в `GAME_PASSWORD`. Пароль чувствителен к регистру.

## Локальный запуск

```sh
cp .env.example .env
npm run dev
```

Откройте http://127.0.0.1:3000. Команда собирает клиент и запускает Fastify.
Готовую сборку можно запустить отдельно командой `npm start`; сервер читает
настройки из `.env`.

Чтобы проверить игру с телефона в той же Wi-Fi сети, задайте `HOST=0.0.0.0`
в `.env` и откройте `http://<IP-Mac>:3000`. Если порт 3000 занят, смените его
параметром `PORT`.

На сервере с HTTPS задайте `NODE_ENV=production`, чтобы включить защищённую
cookie. База данных по умолчанию находится в `./data/game.sqlite`; храните её
на постоянном диске, чтобы профили, сессии и рейтинги переживали перезапуск.

Ник содержит от 1 до 32 символов. Крайние пробелы удаляются, регистр при
поиске профиля игнорируется, а исходное написание сохраняется. Сессия действует
7 дней. Для выхода откройте паузу. После 10 неверных паролей с одного IP вход
блокируется до конца минутного окна.

## Проверки

```sh
npm run typecheck
npm run build
npm test
npm run test:e2e
npm run format:check
```

`npm run check` запускает сборку, тесты с покрытием и браузерные тесты.
Порог покрытия — 100% строк, функций, ветвей и statements для собственного
исполняемого кода в `server`, `client` и `scripts`. CI выполняет форматирование,
сборку, тесты покрытия и Playwright в Chromium и WebKit.

Playwright запускает собранный сервер на свободном порту 3000. При
необходимости его можно задать явно, например:
`PLAYWRIGHT_PORT=3001 npm run test:e2e`.

Визуальные эталоны Linux для Chromium и WebKit хранятся рядом с тестами в
`tests/e2e/foundation.spec.ts-snapshots/`. Для подготовки кандидатов запустите
на Linux:

```sh
npm run test:visual -- --update-snapshots
```

Перед добавлением снимков просмотрите их и различия: проверьте читаемость,
обрезку и размеры 1280×720, 844×390 и 390×844 в обоих браузерах. Локальные
эталоны macOS и Windows находятся в игнорируемой `.visual-baselines/` и не
заменяют эталоны Linux CI. Фактические снимки, различия, видео, трассы и отчёты
в Git не добавляются.
